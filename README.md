Design isn't a coat of paint at the end. I start every project with the user's flow, then build a small design system and carry it into code.

<table>
  <tr>
    <td width="50%" valign="top">

**🎯 Principles I design by**

- **Clarity first:** clear hierarchy, one primary action per screen
- **Responsive by default:** mobile, tablet and desktop from the first frame
- **Motion with purpose:** micro-interactions that guide, never distract
- **Systems over screens:** tokens for colour, type, spacing and radius
- **Accessible:** AA contrast, readable type, keyboard-friendly UI
- **Fast:** lazy loading, optimised assets, smooth 60 fps animation
